TMCalc
Anti-reflection coating design simulator

An Excel tool that automatically calculates the layer thicknesses with the lowest reflectance — just choose the layer structure and materials and press "Optimize". It uses the same calculation we use for our low-reflection coating GLC (Ghost Less Coating), now available to everyone.

Download free

What it does

  • Automatic thickness optimization

    Set fixed layers and min/max thicknesses, press "Optimize", and TMCalc searches for thicknesses that lower reflectance over your target wavelength range. The current thicknesses are included as a candidate, so the result never gets worse.

  • Several conditions at once

    Evaluate up to three conditions together, such as normal (0°) and oblique (e.g. 40°) incidence. Thinner films at the lens edge can be entered as a "ratio".

  • Polarization

    Choose unpolarized (S/P average), S-polarized only or P-polarized only.

  • Measured data and analysis

    Paste measured reflectance to compare with the design, estimate the thickness of each layer, and get the top-coat target that compensates for PVD deviation.

  • Material and substrate tables

    Materials are registered with Hartmann formula coefficients. If you only know the index nd, a helper creates the coefficients.

  • Output sheet

    A reflectance table and chart for 0–40° (10° steps) over 380–1500 nm, rewritten automatically whenever the design changes.

How to use

  1. Download the file in your language below.
  2. Open it in Excel and choose "Enable Macros" (charts and result formulas display even without macros).
  3. On the "Design" sheet, choose the design type, substrate and the material of each layer, then enter the evaluation conditions (angle of incidence) and target wavelength range.
  4. Press "Optimize" and the thicknesses are set automatically. Check the result table and chart against your spec.

Requirements and notes

  • Use Microsoft Excel (desktop version). Tested with Excel for Microsoft 365 on Mac. The buttons (macros) do not work in Excel for the web, Google Sheets or Numbers.
  • If Windows blocks the macros, right-click the file → "Properties" → "General", tick "Unblock", press "OK" and open the file again.
  • Assumptions: no absorption (k=0); back-surface reflection of the substrate is not included. The angle of incidence is measured in air. Calculation uses the characteristic matrix method.
  • Material and substrate coefficients are reference values; replace them with the values of your own materials. Results are design guidance and do not guarantee the properties of actual products.
