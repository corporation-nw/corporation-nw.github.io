Co-Packaged Optics とは｜光をチップの隣まで近づける理由

データセンターのスイッチで進む CPO（光電融合）を、なぜ必要になったのか、何が難しいのか、光学部材の作り手に何が求められるのかの順に解説します。

聞き手

聞き手：データセンターの世界で CPO という言葉をよく見かけるようになりました。これは何の略でしょうか。

解説

解説：Co-Packaged Optics の略で、日本語では光電融合と呼ばれることもあります。スイッチの半導体チップのすぐ隣に、光と電気を変換する部品を同じパッケージに載せてしまう技術です。これまで装置の前面に挿していた光モジュールを、チップの横まで引っ越させる、と考えると分かりやすいかもしれません。

聞き手

聞き手：なぜ、わざわざ引っ越させる必要があるのでしょうか。

解説

解説：電気の信号を基板の上で長く引き回すのが、速度の面でも電力の面でも限界に近づいてきたからです。通信の速度が上がるほど、配線を通るあいだに信号は弱くなり、それを補うための回路が電力を食います。光学の部材を作る側から見ると、この変化は仕事の中身が変わることを意味します。順番に見ていきます。

プラガブルから CPO へ、何が変わるのか

聞き手

聞き手：これまでの方式は、どういう形だったのですか。

解説

解説：プラガブル光トランシーバーと呼ばれる、抜き差しできる光モジュールを装置の前面に並べる形です。スイッチの半導体チップから出た電気信号は、基板の配線とコネクタを通って前面まで運ばれ、そこで初めて光に変わります。この「運ぶ距離」が、速度を上げるほど重たくなってきました。

聞き手

聞き手：距離が問題になるというのは、どのくらいの影響なのでしょう。

解説

解説：NVIDIA の技術資料では、200ギガビット毎秒のチャネルで最大22 dB の電気的な損失が生じると説明されています。信号が目減りするぶん、送る側で強く押し出し、受ける側で整える必要があります。CPO にしてチップの隣で光に変えると、この損失はおよそ4 dB まで下がるとされています。

聞き手

聞き手：損失が減ると、何が良くなるのですか。

解説

解説：補正のための回路が小さくて済み、電力が下がります。同じ資料では、インターフェースあたり30W ほどだった消費電力が9W まで下がり、以前の構成と比べて電力効率は3.5倍になると説明されています。信号の品質は64倍、故障しうる光部品の数が減ることで信頼性は10倍という数字も挙げられています。

光に変える場所装置の前面スイッチチップのすぐ隣
電気の損失（200Gb/s）最大22 dBおよそ4 dB
インターフェースあたりの電力30W 程度9W まで
抜き差しできる基本的にできない
聞き手

聞き手：抜き差しできないのは、運用する側にとっては不安がありそうです。

解説

解説：そこは後で触れます。まず、なぜここまでして光を近づけるのか、その事情を見ておきます。

電気で運ぶ限界が、光を内側へ呼び込んだ

聞き手

聞き手：AI 向けのデータセンターが増えたことと、関係があるのでしょうか。

解説

解説：大きく関係しています。Broadcom の発表では、生成 AI のクラスターでは光の接続が前段のネットワークでも後段でも欠かせず、プラガブル光トランシーバーがシステム全体の電力のおよそ50%、コストの半分以上を占めると説明されています。GPU が増え、1台あたりの帯域が上がるほど、この割合は効いてきます。

聞き手

聞き手：つまり、通信そのものより、通信を支える部分が重くなっているということですね。

解説

解説：そのとおりです。計算する側をいくら速くしても、つなぐ側が電力と費用を食い続けると、全体としては割に合わなくなります。だから各社は、電気で運ぶ区間をできるだけ短くして、早い段階で光に移そうとしています。

聞き手

聞き手：実際の製品は、どのくらいの規模のものですか。

解説

解説：Broadcom が2024年3月に顧客への出荷を発表した Bailly は、毎秒51.2テラビットのイーサネットスイッチです。6.4テラビットのシリコンフォトニクス光エンジンを8個、スイッチチップと組み合わせた構成で、光の接続にかかる電力はプラガブルと比べて70%低く、シリコンの面積効率は8倍と説明されています。

CPO が狙っているもの

  • 電力：補正回路を減らし、接続あたりの消費電力を下げる
  • 面積：装置前面のスペースに縛られず、帯域を増やせる
  • 信号：経路が短くなり、品質が保ちやすくなる
  • 費用：部品点数と電力の両面で、運用の負担を軽くする
聞き手

聞き手：日本でも同じ流れがあるのでしょうか。

解説

解説：NTT が進めている光電融合が、まさにこの領域です。研究所の記事では、第2世代のデバイス PEC-2 について、1台あたり32チャネル、合計3.2テラビット毎秒の帯域を扱えると説明されています。消費電力12W の従来型トランシーバー8台分に比べ、48W と半分に抑えられるという数字も挙げられています。

聞き手

聞き手：日本の技術が、世界の流れの中に入っているのですね。

解説

解説：同じ記事では、6.4テラビット毎秒の PEC-2 を毎秒102.4テラビットのスイッチチップに実装し、従来のスイッチ装置と比べて50%の電力削減を目指す、という開発の方向も示されています。ここから先は、部材を作る側の話に移ります。

1つの光エンジンに、数百点の光学部品

聞き手

聞き手：光エンジンというのは、中に何が入っているのですか。

解説

解説：Broadcom の説明では、Bailly の光エンジン1つに数百点の光学部品と数億個のトランジスタが集積されています。光源、電気と光を変換する素子、波長を合成・分離する部分、そしてファイバーへ光を導く結合部まで、まとめて1つの小さな部品に収まっています。光学部品が「装置に取り付ける部品」から「半導体の中に組み込む部品」へ移っているのが、この分野の大きな変化です。

聞き手

聞き手：組み込む部品になると、何が変わるのでしょうか。

解説

解説：求められる精度の桁が変わります。光導波路とファイバーの結合では、位置がわずかにずれるだけで光の量が落ちます。Broadcom は、端面で結合するファイバー取り付けを高度に自動化した製造方法によって量産を可能にした、と説明しています。精度を職人の手ではなく、工程の設計で担保するという発想です。

聞き手

聞き手：光学部材の作り手には、どんな要求が来るのでしょうか。

解説

解説：波長ごとの透過率や反射率に加えて、半導体の工程に耐えるかどうかが問われます。実装のときの温度、樹脂や接着剤から出るガス、微細な異物、そして長期間の信頼性です。どれも、カメラ向けの部材で積み上げてきた考え方と地続きです。

要求される点具体的に見られること
光学特性使う波長での透過率と反射率、迷光の抑え方
寸法と位置結合部の位置ずれ、面の精度、角度の公差
環境への耐性実装時の熱、高温高湿、長期の安定性
清浄度異物、欠陥の大きさの基準、内部が曇る原因になるガス
聞き手

聞き手：組み上がった光エンジンの良し悪しは、どうやって確かめるのでしょうか。

解説

解説：中を直接のぞけないので、光を入れて出てくる量や波形で判断します。ここで効いてくるのが、測る側と作る側で数値がそろっているかどうかです。同じサンプルを双方で測って値が合わない状態では、良品と不良品の線引きそのものが成り立ちません。測定の条件をそろえる作業は地味ですが、量産の立ち上げでは最初にぶつかる壁です。

聞き手

聞き手：不良が見つかったときは、どう進めるのですか。

解説

解説：どの工程で生まれたのかを切り分けていきます。光源なのか、結合部の位置ずれなのか、実装のときの熱や応力なのか。原因が特定できたら、同じ条件で作った製品すべてに水平展開して確認します。部品が一体化しているぶん、切り分けの手間は増えます。

「光学部品が減る」わけではない

  • CPO では装置の前面に並ぶモジュールの数は減りますが、1つの光エンジンの中に入る光学部品は増えています
  • 外から見える部品が減るぶん、中の部品には交換できない前提の信頼性が求められます
  • 量産では、特性の良し悪しよりも「ばらつきの小ささ」で採否が決まる場面が増えます

現場で何が難しいのか

聞き手

聞き手：技術として難しいのは、どのあたりでしょうか。

解説

解説：4つに整理できます。1つ目は熱です。発熱するスイッチチップのすぐ隣に、温度で特性が変わる光の部品を置くことになります。2つ目は結合で、光導波路とファイバーの位置合わせを量産の速度で繰り返す必要があります。

聞き手

聞き手：残りの2つは何ですか。

解説

解説：3つ目は保守です。プラガブルなら不良のモジュールだけ抜いて替えられますが、CPO では簡単にいきません。4つ目は歩留まりで、高価なスイッチチップと光エンジンを同じパッケージに載せるため、どちらか一方の不良が全体の損失になります。一体化で得をする部分と、一体化で失う自由度の、その差し引きで採用が決まります。

手順

  1. スイッチチップと光エンジンを同じ基板の上に配置する
  2. 光導波路とファイバーの位置を合わせ、端面で結合する
  3. 光源からの光を安定して供給する（外に出す構成もある）
  4. 熱の逃げ道を設計し、温度による特性の変化を抑える
  5. 不良が出たときの切り分けと、交換の手順を決めておく
聞き手

聞き手：光源を外に出す、というのはどういうことでしょうか。

解説

解説：レーザーは熱に弱く、寿命の面でも弱点になりやすい部品です。そこで光源だけをパッケージの外に置き、光ファイバーで中へ導く構成が取られることがあります。交換しやすくなる一方で、導く経路での損失や、戻り光を抑える部品が新たに要ります。どちらの構成にも一長一短があります。

日本・中国・台湾の、それぞれの役割

聞き手

聞き手：この分野では、どの地域が強いのでしょうか。

解説

解説：役割が分かれています。日本は材料と、光源や受光素子の周辺に強みがあり、NTT の光電融合のように研究から製品化へ進めている例もあります。台湾は半導体の後工程と実装の層が厚く、スイッチチップと光エンジンを1つのパッケージにまとめる工程が得意です。中国は量産の規模と、部材の価格競争力を持っています。

聞き手

聞き手：1つの国で完結しない、ということですね。

解説

解説：完結しません。だからこそ、どこで何を作り、どこで組み上げるかの設計が重要になります。部材の仕様を決める段階で、実装する側の工程を知らないと、量産に入ってから手戻りが起きます。測定の方法と基準を、取引先とそろえておくことも欠かせません。

聞き手

聞き手：カメラ向けの部材を作ってきた会社にも、関わる余地はありますか。

解説

解説：あります。波長ごとの設計、反射の抑え方、異物と欠陥の管理、量産でのばらつきの詰め方は、分野が変わっても共通しています。扱う波長と要求精度は違いますが、考え方の土台は同じです。

まとめ

聞き手

聞き手：CPO は、電気で運ぶ距離を短くするために光をチップの隣まで近づける技術で、電力とコストの問題が背景にある。そして光学部品は、装置に取り付けるものから半導体に組み込むものへ変わりつつある、ということですね。

解説

解説：そのとおりです。外から見える光学部品は減っても、中で求められる精度と信頼性は上がっています。カメラの分野で積み上げてきた、波長ごとの設計や異物の管理、ばらつきを抑える工程の考え方は、この領域でも通用します。NW では、低反射コーティングや遮光インキといった光学部材を扱っています。くわしくは製品・サービスをご覧ください。

よくある質問

CPO（Co-Packaged Optics）とは何ですか

スイッチの半導体チップのすぐ隣に、電気と光を変換する光エンジンを同じパッケージとして載せる技術です。日本語では光電融合と呼ばれることもあります。装置の前面に挿すプラガブル光トランシーバーに代わる方式として開発が進んでいます。

CPO にすると、どのくらい電力が下がるのですか

NVIDIA の技術資料では、インターフェースあたり30W程度だった消費電力が9Wまで下がり、電力効率は以前の構成と比べて3.5倍になると説明されています。Broadcom は、自社の51.2テラビット毎秒のスイッチで、光の接続にかかる電力がプラガブルと比べて70%低いとしています。

なぜ今、CPO が注目されているのですか

生成AI向けのクラスターでは、プラガブル光トランシーバーがシステム電力のおよそ50%、コストの半分以上を占めるとされています。計算する側の性能が上がるほど、つなぐ側の電力と費用が全体の足かせになるためです。

CPO のデメリットは何ですか

不良が出た光の部分だけを抜いて交換することが難しくなります。また、発熱するスイッチチップの隣に温度に敏感な光部品を置くため熱の設計が難しく、高価なチップと光エンジンを同じパッケージに載せるぶん、どちらか一方の不良が全体の損失になります。

日本では CPO に関する動きはありますか

NTT が光電融合として取り組んでいます。研究所の記事では、第2世代デバイス PEC-2 が1台あたり32チャネル・合計3.2テラビット毎秒を扱い、消費電力12Wの従来型トランシーバー8台分に比べて48Wと半分に抑えられると説明されています。
