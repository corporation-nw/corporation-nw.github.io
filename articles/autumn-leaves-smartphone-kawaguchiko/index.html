スマホで撮る紅葉のコツ｜河口湖もみじ回廊の作例で解説

河口湖もみじ回廊で撮った作例写真を見ながら、逆光の使い方、見上げる構図、望遠で富士山と重ねる方法、水面や落ち葉の撮り方を解説します。見頃の時期とライトアップの時間も紹介。

目次

  1. もみじ回廊はどんな場所か
  2. 紅葉がいちばん鮮やかに写る光の向き
  3. 見上げて撮る・色を重ねる構図
  4. 望遠で富士山と紅葉を重ねる
  5. 水面と落ち葉を撮る
  6. まとめ
聞き手

聞き手：紅葉の季節になると、スマホで撮った写真が思ったより地味に見えてがっかりすることがあります。目で見たときはあんなに赤かったのに、どうして写真だとくすんでしまうんでしょうか。

解説

解説：よくある悩みです。原因の多くは、スマホの性能よりも「どちらから光が当たっているか」と「どこを切り取るか」にあります。ここでは、山梨県富士河口湖町の「もみじ回廊」で、2025年の秋に vivo X200 Ultra で撮った作例を見ながら、光の向き、構図、望遠、水面や落ち葉の撮り方を順番に見ていきます。

聞き手

聞き手：実際の写真を見ながらだと分かりやすそうです。まずは、もみじ回廊がどんな場所なのかから教えてください。

解説

解説：撮り方の前に、場所の特徴を知っておくと狙いが立てやすくなります。次の章で、見頃の時期や時間帯も含めて紹介します。

もみじ回廊はどんな場所か

聞き手

聞き手：写真を見ると、道の両側から紅葉がかぶさってトンネルのようですね。これはどういう場所なんですか。

解説

解説：河口湖の北側、梨川という川の両岸に沿って、もみじが連なっている場所です。山梨県の公式観光サイトによると、両岸のおよそ150メートルにわたって、樹齢を重ねた巨木を含む約60本のもみじが並んでいます。散策は無料で、自由に歩けます。

聞き手

聞き手：150メートルなら、ゆっくり歩いても撮りきれそうな長さですね。見頃はいつごろですか。

解説

解説：同じサイトでは、例年10月下旬に色づき始め、11月上旬から中旬が見頃のピーク、11月中旬から下旬は落ち葉が地面を覆う時期とされています。富士河口湖町観光連盟の案内でも、見頃は例年10月下旬から11月中旬です。赤い葉を撮るなら11月上旬から中旬、落ち葉の絨毯を撮るなら11月中旬以降と、撮りたいものに合わせて時期を選べます。

時期（例年）見られるもの撮りやすい被写体
10月下旬色づき始め緑と赤が混ざったグラデーション
11月上旬〜中旬見頃のピーク頭上を覆う赤いトンネル、富士山との組み合わせ
11月中旬〜下旬落ち葉の絨毯地面や水面に積もった葉
聞き手

聞き手：夜も撮れるんでしょうか。

解説

解説：見頃に合わせて「富士河口湖紅葉まつり」が開かれ、期間中は毎日、日没の16時30分ごろから21時30分までライトアップされます。昼と夜で雰囲気がまったく変わるので、両方を撮る人も多い場所です。

聞き手

聞き手：昼も夜も楽しめるんですね。では、昼の写真を鮮やかに撮るには、まず何に気をつければいいですか。

解説

解説：いちばん効くのが光の向きです。次の章で、同じ紅葉でも光の当たり方でどれだけ違って見えるかを説明します。

紅葉がいちばん鮮やかに写る光の向き

聞き手

聞き手：この写真は、葉っぱ自体が光っているように見えます。何が違うんですか。

解説

解説：葉の裏側から光が透けている、いわゆる透過光で撮っているからです。OM SYSTEM の作例解説でも、葉の表側ではなく、裏側から逆光になる向きにカメラを向けて撮ることを勧めています。葉を光に透かすと、赤や黄色がステンドグラスのように明るく出ます。

聞き手

聞き手：逆光というと、顔が暗くなる失敗写真のイメージがあります。紅葉では逆にいいんですね。

解説

解説：人物の場合とは狙いが違います。タムロンの解説によると、逆光は被写体の後ろから光が当たる向きで、葉の輪郭で光が散乱し、きれいな光の筋が得られます。一方、横から当たるサイド光は、陰影が強調されて葉の凹凸や立体感が際立つとされています。

光の向き写り方向いている撮り方
順光（正面から）色は出るが平面的になりやすい山全体の色づきなど、広い景色
サイド光（横から）陰影で葉の凹凸や立体感が出る幹や枝ぶりを見せたいとき
逆光（後ろから）葉が透けて明るく、輪郭が光る頭上の葉、1枝のアップ
聞き手

聞き手：スマホで逆光を撮ると、画面全体が暗くなってしまうことがあります。

解説

解説：そのときは明るさを調整します。多くのスマホでは、ピントを合わせたい所を画面でタップすると、明るさを上下に動かすつまみが出ます。逆光で葉が暗く写ったら、明るさを少しプラス側に上げると、透けた葉の色がよみがえります。

聞き手

聞き手：逆に、明るくしすぎることはありますか。

解説

解説：あります。空まで入れて明るくしすぎると、空が真っ白に飛んでしまいます。OM SYSTEM の作例には、背景が影になっている場所で、光が当たっている葉だけを選び、明るさを大きく下げて背景を黒く沈めた例もあります。背景を暗く落とすと、光の当たった葉だけが浮かび上がります。

光の向きで迷ったら

  • 頭上の葉や1枝のアップは、葉の裏側から光が透ける逆光で撮る
  • 葉が暗く写ったら、画面をタップして明るさを少しプラスにする
  • 背景が影の場所では、明るさを下げて背景を黒く沈めると葉が際立つ
聞き手

聞き手：光の向きだけで、ずいぶん違いが出るんですね。次は構図でしょうか。

解説

解説：はい。紅葉は画面いっぱいに色があるぶん、構図を決めないと散らかった写真になりがちです。次の章で、見上げて撮る方法と色の組み合わせ方を見ていきます。

見上げて撮る・色を重ねる構図

聞き手

聞き手：木の真下から見上げた写真ですね。普段あまりしない角度です。

解説

解説：見上げて撮ると、背景が空だけになるので、電線や建物、人混みが入りにくくなります。晴れた日なら青空が赤や黄色の補色に近い背景になり、紅葉の色がいっそう引き立ちます。葉の裏側から光が透けるので、前の章の逆光とも相性がいい撮り方です。

聞き手

聞き手：画面の中のどこに木を置けばいいか、いつも迷います。

解説

解説：基本として覚えやすいのが三分割構図です。タムロンの解説によると、画面を縦横それぞれ3等分し、その交点に主な被写体を置く方法です。スマホのカメラ設定で「グリッド」や「ガイド線」を表示にしておくと、線の交わる所に幹や一番赤い枝を置くだけで、落ち着いた写真になります。

聞き手

聞き手：色についてはどうでしょう。赤だけのほうがきれいですか。

解説

解説：赤だけで埋めるより、黄色や緑、空の青を少し混ぜると、赤の強さが際立ちます。もみじ回廊は赤いもみじのほかに黄色く色づく木もあるので、赤と黄色を重ねて奥行きを出すのがおすすめです。

聞き手

聞き手：色を濃くしたくて、フィルターで彩度を上げることもあるんですが。

解説

解説：やりすぎには注意が必要です。OM SYSTEM の解説でも、もともと色のしっかりした被写体を鮮やかな設定にすると、彩度が高くなりすぎて、絵の具をベタっと塗ったような仕上がりになると指摘しています。紅葉はそれ自体の色が強いので、まずは標準の設定で撮り、足りなければ後から少しだけ調整するくらいがちょうどいいでしょう。

色を盛りすぎない

  • 紅葉は、もともと色の強い被写体です。彩度を大きく上げると不自然な色になりやすい
  • まずは標準の設定で撮り、編集で少しずつ調整する
  • 夕方の光は赤みが強くなるので、そのまま残すと季節感が出る
聞き手

聞き手：なるほど、強い色を扱うからこそ、控えめにするほうがいいんですね。

解説

解説：そうです。そして、河口湖ならではの撮り方がもう1つあります。紅葉と富士山を1枚に収める方法を、次の章で紹介します。

望遠で富士山と紅葉を重ねる

聞き手

聞き手：手前の赤いもみじと、奥の富士山が一緒に写っていますね。これは広角で撮るんですか、望遠で撮るんですか。

解説

解説：どちらでも撮れますが、狙いが変わります。広角で撮ると、手前のもみじが大きく、富士山は小さく遠くに写ります。望遠に切り替えると、遠くの富士山が大きくなり、手前の紅葉との距離が縮まったように見えます。富士山を主役にしたいなら望遠が向いています。

聞き手

聞き手：スマホの「2倍」「3倍」のボタンも、その望遠にあたるんでしょうか。

解説

解説：考え方は同じです。タムロンの解説では、焦点距離がおよそ80mm以上の望遠レンズは、遠くの紅葉をクローズアップし、離れた場所から葉の細部を捉えるのに向いているとされています。スマホでも、望遠用のカメラを備えた機種なら、画質を落とさずに遠くを大きく写せます。

聞き手

聞き手：望遠のカメラがないスマホで、画面を指で広げて拡大するのとは違うんですか。

解説

解説：違います。望遠用のカメラがない場合、画面を広げる拡大は、撮った画像の一部を切り出して引き伸ばす処理になるため、細部が甘くなりがちです。富士山の雪や枝先の葉のように、細かい部分を見せたい写真ほど差が出ます。

撮り方富士山の写り方向いている写真
広角（1倍前後）小さく遠くに写る回廊全体、紅葉のトンネル
望遠（望遠用のカメラ）大きく写り、手前との距離が縮んで見える富士山を主役にした紅葉
指で拡大（望遠用のカメラなし）大きく写るが細部が甘くなりやすい記録用、SNS の小さな表示
聞き手

聞き手：富士山は、いつでも見えるわけではないですよね。

解説

解説：雲に隠れて見えない日もあるので、見えているうちに先に撮っておくのがおすすめです。見えない日は、次の章の水面や落ち葉に狙いを切り替えましょう。

水面と落ち葉を撮る

聞き手

聞き手：水面に浮かんだ葉っぱの写真ですね。これは足元を撮ったんですか。

解説

解説：そうです。もみじ回廊は川沿いにあるので、足元の水面にも葉が浮かびます。タムロンの解説でも、湖や池に映る紅葉は幻想的な光景を作るとしたうえで、風のない晴れた日を選び、三脚を使ってシャッターを遅くすると、水面をなめらかに表現できるとしています。

聞き手

聞き手：スマホで三脚を使うのは、少し大げさな気がします。

解説

解説：手持ちでも十分楽しめます。ポイントは、葉と空の映り込みを同時に入れることです。水面の角度を少し変えるだけで、映り込む空や木の色が変わるので、何枚か角度を変えて撮り比べてみてください。

聞き手

聞き手：落ち葉のほうはどうですか。地面を撮っても、ただ散らかっているように見えてしまいます。

解説

解説：タムロンの解説では、落ち葉の配置や色の組み合わせに注目し、自然の中の美しい模様を見つけるのも面白いとしています。たとえば、切り株の上に1枚だけ乗った葉や、赤と黄色が交互に重なった場所を探すと、主役がはっきりします。見頃の後半、11月中旬以降は地面が落ち葉で覆われるので、こうした撮り方に向いた時期です。

手順

  1. 足元の水面や地面で、色の違う葉が集まっている場所を探す
  2. 主役にする葉を1枚か1か所だけ決める
  3. 画面のグリッドの交点に主役を置く
  4. 水面は角度を変えて、空や木の映り込みを何枚か撮り比べる
聞き手

聞き手：人が多い時期だと、足元を撮るときに周りが気になります。

解説

解説：そこはマナーの面でも大事です。最後に注意点を確認しておきましょう。

撮影するときの注意

  • 見頃の時期は人出が多いので、通路をふさいで長く立ち止まらない
  • 三脚や自撮り棒は、混雑しているときは使わない
  • 川沿いでは足元に気をつけ、柵の内側から撮る
  • 富士河口湖町観光連盟の案内にもあるとおり、秋の夜は冷え込むので、ライトアップを撮るなら防寒の用意をする
聞き手

聞き手：気持ちよく撮るためにも、周りへの気配りは欠かせませんね。

解説

解説：そうですね。最後に、ここまでのポイントを振り返ります。

まとめ

聞き手

聞き手：紅葉を鮮やかに撮るには、葉を透かす逆光で撮ること、見上げたり赤と黄色を重ねたりして構図を決めること、富士山を大きく入れたいなら望遠を使うこと、そして水面や落ち葉にも目を向けること、ですね。

解説

解説：そのとおりです。スマホでも、光の向きと切り取り方を意識するだけで、紅葉の写りは大きく変わります。もみじ回廊の見頃は例年11月上旬から中旬なので、時期を合わせて出かけてみてください。作例に使った vivo X200 Ultra のカメラには、NW が扱うゴースト抑制のコーティング GLC 2.0 が採用されています。望遠スマホを試してみたい方は、NW Mobile のページもご覧ください。

よくある質問

もみじ回廊の紅葉の見頃はいつですか

山梨県の公式観光サイトでは、例年10月下旬に色づき始め、11月上旬から中旬が見頃のピーク、11月中旬から下旬は落ち葉の絨毯が見られる時期とされています。

もみじ回廊のライトアップは何時までですか

見頃に合わせて開かれる富士河口湖紅葉まつりの期間中、日没の16時30分ごろから21時30分まで、毎日ライトアップされます。散策は無料です。

スマホで紅葉を鮮やかに撮るコツは何ですか

葉の裏側から光が透ける逆光で撮るのが効果的です。葉が暗く写ったときは、画面をタップして明るさを少しプラス側に調整します。

富士山と紅葉を一緒に撮るには、広角と望遠のどちらがよいですか

回廊全体を入れたいなら広角、富士山を大きく主役にしたいなら望遠が向いています。望遠用のカメラを使うと、画像を切り出して拡大するよりも細部まできれいに写せます。

彩度を上げると紅葉はきれいになりますか

上げすぎると不自然になりやすいので注意が必要です。紅葉はもともと色の強い被写体なので、標準の設定で撮り、編集で少しずつ調整するのがおすすめです。
