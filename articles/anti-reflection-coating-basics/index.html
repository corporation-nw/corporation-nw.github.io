反射防止コーティングのしくみ｜屈折率と多層膜の基本

レンズの表面反射はなぜ起きるのか。屈折率の差と光の干渉から、単層膜・多層膜の反射防止コーティングの原理を、出典つきの数値で解説します。

聞き手

聞き手：眼鏡のレンズやカメラのレンズって、光を通すためのものなのに、ちょっと角度を変えると表面がうっすら光って見えますよね。あれは何が起きているんですか。

解説

解説：それは表面で反射した光です。ガラスは透明ですが、光がすべて通り抜けるわけではありません。空気からガラスに入る瞬間、屈折率が変わる境界面で、光の一部がはね返されます。屈折率は、光がその物質の中でどれだけ速度を落とすかを表す数値で、空気はほぼ1.00、一般的な光学ガラスはおよそ1.5前後です。

聞き手

聞き手：屈折率の差があると反射する、という理屈はなんとなく分かります。どれくらいの光が実際に失われているのか、次で教えてください。

反射はなぜ起きるのか｜屈折率の差が光をはね返す

解説

解説：キヤノンの技術解説では、レンズの表面反射によって約4%の光が失われるとされています。1枚のレンズには表と裏の2つの面があるので、1枚を通過するだけで光量はおよそ8%減ります。カメラレンズのように5枚から10枚のレンズを組み合わせた光学系では、コーティングをしていなければ透過率は半分以下まで落ち込みます。

聞き手

聞き手：それは想像していたより大きいですね。この反射率は、計算で求められるものなんですか。

解説

解説：はい。垂直に光が入る場合の反射率は、境界の両側の屈折率だけで決まります。京都産業大学の光学講義資料では、垂直入射のときの振幅反射率を rs = (n1 − n2)/(n1 + n2) と表し、強度としての反射率はこの絶対値を2乗すれば求まる、と説明されています。n1が入射側（空気）、n2が出ていく側（ガラス）の屈折率です。ニコンの技術解説でも、光の干渉現象を利用して、膜に用いる材料の屈折率と厚さを設計することで反射を減らす、という考え方が示されています。

垂直入射での反射率の考え方

  • 振幅反射率：rs = (n1 − n2) / (n1 + n2)
  • 強度としての反射率：R = rs の2乗
  • n1・n2 の差が大きいほど、R は大きくなる
聞き手

聞き手：なるほど、屈折率の差そのものが反射の大きさを決めているんですね。反射防止コーティングは、この反射をどうやって減らしているんですか。

単層膜のしくみ｜光をわざとぶつけて打ち消す

解説

解説：塗る、というより「もう一つ反射面を足す」というのが近い表現です。ガラスの上に、屈折率も厚さも決まった薄い膜を1層のせると、反射する場所が2か所になります。1つは空気と膜の境界、もう1つは膜とガラスの境界です。この2つの反射光の位相をずらして重ねると、山と谷が打ち消し合って、反射光そのものが弱まります。

聞き手

聞き手：膜の厚さは、どうやって決めているんですか。

解説

解説：PVEducationの解説では、膜の中を進む光の波長が、入ってくる光の波長のちょうど4分の1になるように膜厚を選ぶ、とされています。式で書くと d1 = λ0 / (4n1) です。λ0が空気中での波長、n1が膜の屈折率です。この厚さのとき、2つの反射光がちょうど逆位相になり、打ち消し合う量が最大になります。同じ解説では、これらの反射光が互いに打ち消し合い、反射エネルギーが正味ゼロになる、とも述べられています。

聞き手

聞き手：位相がずれて打ち消し合う、という理屈は分かりました。膜の屈折率そのものは、何でもいいわけではなさそうですね。

解説

解説：そのとおりです。膜の屈折率が両側の媒質（空気とガラスなど）の屈折率の幾何平均になっているとき、反射がさらに小さくなるとされています。式にすると n1 = √(n0・n2) です。この条件と、先ほどの4分の1波長の厚さの条件が両方そろうと、2つの反射光の振幅までほぼ等しくなり、打ち消し合いがもっとも深くなります。

聞き手

聞き手：理屈のうえではきれいに消えそうですが、実際の材料でそこまでうまくいくものなんですか。

なぜ単層膜では反射がゼロにならないのか

解説

解説：実際に使われている膜の材料でもっとも標準的なのが、フッ化マグネシウム（MgF2）で、屈折率はおよそ1.38です。島津製作所の解説によると、屈折率1.46の石英ガラスの上に、このMgF2を4分の1波長の厚さ（波長550ナノメートルの場合）でコーティングすると、その波長での反射率は1.79%まで下がるとされています。無コーティングの約4%と比べると半分以下ですが、ゼロにはなっていません。

聞き手

聞き手：1.79%ということは、さっき言っていた「幾何平均」の条件とは、ずれているということですか。

解説

解説：そこがこの技術のおもしろいところです。石英ガラス（屈折率1.46）に対する理想の膜の屈折率は √(1×1.46) で、およそ1.21です。ところがMgF2の屈折率は1.38なので、理想値より高く、条件がぴったり合っていません。だから反射はゼロにならず、1.79%残ります。一方で同じ解説では、屈折率1.79のサファイアにMgF2をコーティングした場合、ほぼ0%まで反射率を下げられるとも述べられています。

聞き手

聞き手：サファイアだとうまくいくのはなぜですか。

解説

解説：サファイアに対する理想の屈折率は √(1×1.79) で、およそ1.34です。MgF2の1.38はこれにかなり近いので、幾何平均の条件にほぼ合致します。同じMgF2という材料でも、下にあるガラスの種類によって、反射をどこまで減らせるかが変わるということです。

コーティング=反射ゼロ、ではない

反射防止コーティングを1層のせれば必ず反射が消える、というのは誤解です。膜の屈折率が基材の屈折率に対して最適な値からずれていると、反射は残ります。単層膜で使える材料は限られているため、あらゆる基材で理想の屈折率を用意できるとは限りません。

聞き手

聞き手：単層膜には限界がある、ということですね。それなら、複数の波長にまとめて対応させることはできないんですか。

多層膜でどう改善するのか｜層を重ねて帯域を広げる

解説

解説：できます。それが多層膜です。ニコンの技術解説では、カメラのように可視光の広い波長帯域を扱う場合、各波長で反射を防げるように、屈折率の異なる材料による多層膜を設計する、と説明されています。屈折率の高い膜と低い膜を交互に重ねることで、干渉が起きる場所を増やし、単層膜よりも広い波長範囲で反射を抑えられるようにする考え方です。

聞き手

聞き手：層を増やすと、どこまで反射を減らせるんですか。

解説

解説：島津製作所の解説によれば、コーティングを数層にすることで、石英ガラスのような基材でも、単一の波長に限れば反射率をほぼ0%にできるとされています。さらに層数を増やすことで、複数の波長、あるいは可視光全体のような広い帯域でも、反射率をほぼ0%に近づける設計が可能になるとも述べられています。

膜の種類反射を抑えられる範囲代表的な材料・構成
単層膜特定の波長1点に対して最適化MgF2（屈折率約1.38）
多層膜（数層）単一波長でほぼ0%まで低減高屈折率材料と低屈折率材料を交互に積層
多層膜（層数を増やす）複数波長・広帯域でほぼ0%に近づける積層数を増やした設計
聞き手

聞き手：なるほど、層を重ねること自体が目的ではなく、対応したい波長の範囲を広げるために重ねているんですね。

解説

解説：層の数は「頑丈にするため」ではなく、「打ち消し合いをそろえたい波長の数を増やすため」に増えていきます。設計する側は、各層の屈折率・厚さの組み合わせを、対象にする波長域や入射角の範囲に合わせて計算で決めていきます。この仕組みが、実際のカメラレンズではどれくらいの差を生んでいるのか、次で見てみましょう。

カメラレンズで実際にどれだけ効くのか

解説

解説：先ほど触れたとおり、無コーティングのレンズ1面ではおよそ4%の光が反射で失われます。キヤノンの技術解説では、5枚から10枚ものレンズを組み合わせた一般的なカメラレンズでは、コーティングなしだと全体の透過率が半分以下まで落ち込むとされています。レンズを通るたびに反射で少しずつ光が減っていくので、枚数が増えるほど影響が大きくなります。

聞き手

聞き手：半分以下というのは、かなり暗くなるということですよね。実際の高級レンズではどこまで改善されているんですか。

解説

解説：同じ解説によれば、多層膜コーティングを施したキヤノンの高級レンズでは、紫外線から近赤外線までの広い波長域にわたって、99.9%もの光透過率を実現しているとされています。さらに、同社が開発したSWC（Subwavelength Structure Coating）という技術では、反射光の発生をおよそ0.05%にまで抑えられるとも説明されています。

状態光の透過・反射の目安
無コーティングのレンズ1面反射でおよそ4%の光が失われる
無コーティングのレンズ5〜10枚構成全体の透過率が半分以下
多層膜コーティングを施したレンズ（紫外〜近赤外）透過率99.9%
SWC技術を用いた面反射光の発生がおよそ0.05%
聞き手

聞き手：透過率が上がるだけでなく、写真の写り方にも関係してきそうですね。

解説

解説：関係します。反射で失われた光の一部は、レンズの中で迷光となり、ゴーストやフレアといった、写真に写り込む余計な光の原因にもなります。反射防止コーティングは、単に光を通しやすくするだけでなく、写りの質そのものにも関わる技術です。

聞き手

聞き手：屈折率の差から始まった話が、写真の写り方まで結びつくんですね。最後に、この技術が使われている分野を教えてください。

まとめ

解説

解説：カメラのレンズや眼鏡だけでなく、太陽電池のパネル表面、ディスプレイの保護ガラス、スマートフォンのカメラモジュールなど、光を効率よく通したい場所には広く使われています。屈折率の差を計算し、膜厚を波長の4分の1に合わせるという基本の考え方は、どの用途でも共通しています。

聞き手

聞き手：反射防止コーティングは、屈折率の差を利用して、わざと2か所で光を反射させ、それを打ち消し合わせる技術ということですね。

解説

解説：そのとおりです。屈折率の差が反射を生み、膜厚と屈折率をそろえることでその反射同士を打ち消す。この基本の考え方の上に、単層膜から多層膜へと、対応できる波長や角度の範囲を広げる工夫が積み重ねられてきました。Corporation NWは2006年に設立し、2018年から光学分野の事業を行っており、ゴースト抑制のコーティングGLC（屈折率フリー設計、Nd 1.15〜1.60）を取り扱っています。反射防止・ゴースト抑制まわりの部材に関心のある方は、製品・サービスのページもご覧ください。

よくある質問

反射防止コーティングをすれば、レンズの反射は完全になくなりますか。

完全にはなくなりません。単層膜の場合、膜の屈折率が基材に対する理想値からずれていると反射が残ります。島津製作所の解説では、屈折率1.46の石英ガラスにMgF2（屈折率1.38）をコーティングした場合、反射率は1.79%まで下がるものの0%にはならないとされています。

なぜ4分の1波長の厚さにするのですか。

膜の表面とガラスとの境界、2か所で反射する光の位相をずらして重ねるためです。PVEducationの解説によれば、この厚さのときに2つの反射光が逆位相になり、打ち消し合う量が最大になります。

単層膜と多層膜では何が違いますか。

単層膜は特定の1つの波長に対して反射を抑える設計です。多層膜は屈折率の異なる膜を重ねることで、ニコンの技術解説にあるように、可視光のような広い波長帯域の各波長で反射を防げるように設計します。

コーティングなしのレンズはどれくらい光を失いますか。

キヤノンの技術解説では、レンズ1面でおよそ4%の光が反射で失われるとされています。5枚から10枚のレンズを組み合わせた一般的なカメラレンズでは、コーティングがなければ全体の透過率が半分以下まで落ち込みます。

反射防止コーティングは写真の写り方にも影響しますか。

影響します。表面で反射した光の一部はレンズ内で迷光となり、ゴーストやフレアの原因になります。反射を抑えることは、光を通す量を増やすだけでなく、写りの質にも関わります。
