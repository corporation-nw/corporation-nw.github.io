减反射膜设计模拟工具
「TMCalc」

只需选择膜层结构和材料，点击「优化」，即可自动算出反射率最低的膜厚的 Excel 工具。我们把自家低反射镀膜 GLC（Ghost Less Coating）开发中使用的计算方法，开放给所有人使用。

主要功能

  • 膜厚自动优化

    设定要固定的层和膜厚上下限后点击「优化」，即可在目标波长范围内找出反射率较低的膜厚。当前膜厚也会列入候选，因此结果不会变差。

  • 同时评估多个条件

    可同时评估中心（0°）和斜入射（例：40°）等最多3个条件。镜片边缘膜层变薄的情况，也可以用「倍率」输入。

  • 切换偏振

    可选择非偏振（S・P平均）、仅S偏振、仅P偏振。

  • 与实测比较・实测分析

    粘贴测得的反射率，即可与设计比较，并计算各层的推定膜厚，以及配合 PVD 偏差的最外层目标值。

  • 材料表・基板表

    用 Hartmann 公式的系数登记材料。只知道折射率 nd 的材料，也有生成系数的栏位。

  • Output 工作表

    每次修改设计，都会自动输出 0〜40°（每10°）・380〜1500nm 的反射率表格和图表。

使用方法

  1. 点击下方按钮，下载所需语言的版本。
  2. 用 Excel 打开，选择「启用宏」（不启用宏也能显示图表和结果公式）。
  3. 在「设计」工作表选择膜设计Type、基板和各层材料，并输入评估条件（入射角）和目标波长范围。
  4. 点击「优化」即可自动确定膜厚。请通过结果表格和图表确认是否符合规格。

使用环境与注意事项

  • 请使用 Microsoft Excel（桌面版）。已在 Mac 版 Microsoft 365 的 Excel 上确认运行。Excel 网页版、Google 表格、Numbers 无法使用按钮（宏）。
  • 在 Windows 上宏被阻止而无法运行时，请右键单击文件 →「属性」→ 勾选「常规」下方的「解除锁定」并点击「确定」，然后重新打开文件。
  • 计算前提：无吸收（k=0），不含基板背面反射。入射角为空气侧的角度。计算采用特征矩阵法。
  • 材料与基板的系数为参考值，请替换为您所用材料的数值。计算结果仅供设计参考，并不保证实际产品的特性。
