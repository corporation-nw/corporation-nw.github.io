2. 搜集的个人信息

在您咨询或登记时，本公司可能请您提供下列资料：

  • 姓名、公司名称、部门・职称
  • 电子邮件、电话号码
  • 咨询内容（想推广的产品・技术、想接触的对象、希望时程等）
  • 抢先登记时的 LINE 登记资料与问卷回答（となり旅）
  • 其他您在咨询过程中提供的资料

3. 利用目的

搜集的个人信息，将在下列目的范围内使用：

  • 回复您的咨询，以及为此与您联系
  • 寄送产品资料・样品、提供报价
  • NW agent 的引荐对象筛选、引荐与商谈支援
  • 向となり旅抢先登记者提供筹备进度与旅游信息
  • 介绍本公司的事业与服务
  • 改善服务，以及规划新服务
  • 依法令所需之处理

4. 提供给第三者

除法令规定的情形外，本公司不会在未事先取得您同意的情况下，将个人信息提供给第三者。

在 NW agent 进行企业引荐时，将事先请您确认提供给引荐对象的资料范围，并在取得您的同意后提供。

5. 于日本以外地区的处理

本公司于中国（上海）与台湾（台北）设有据点，视咨询内容，可能于这些国家・地区处理个人信息。届时，本公司将在掌握当地个人信息保护制度的前提下，采取必要的安全管理措施。

若需将个人信息提供给位于外国的第三者（例如海外的引荐对象企业），本公司将依法令告知提供对象所在的国家・地区名称，以及当地的个人信息保护制度等信息，并事先取得您的同意。

6. 业务委托

本公司可能在利用目的范围内，将部分个人信息的处理委托给外部业者。届时将慎选受托者，并进行必要且适当的监督。

7. 安全管理

为防止个人信息外泄、灭失或毁损，本公司将限制可存取的人员，并采取其他必要且适当的安全管理措施。

  • 本网站通过 GitHub Pages（GitHub, Inc.）公开。该公司可能记录浏览者的 IP 位址等存取纪录。
  • 文字显示使用 Google Fonts（Google LLC）。显示页面时，浏览者的 IP 位址等信息会传送至该公司。
  • となり旅的抢先登记使用 LINE（LY Corporation）。LINE 上的资料处理，依该公司的隐私政策办理。
  • NW agent 咨询表单的内容，将通过 Formspree（Formspree, Inc.）寄送至本公司。以电子邮件咨询时，将由浏览者的邮件软件寄送至本公司。

本网站目前未使用流量分析或广告用途的 Cookie。若日后开始使用，将修订本政策并公告。
