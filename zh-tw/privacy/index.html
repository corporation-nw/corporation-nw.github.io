2. 蒐集的個人資料

在您洽詢或登記時，本公司可能請您提供下列資料：

  • 姓名、公司名稱、部門・職稱
  • 電子郵件、電話號碼
  • 諮詢內容（想推廣的產品・技術、想接觸的對象、希望時程等）
  • 搶先登記時的 LINE 登記資料與問卷回答（となり旅）
  • 其他您在洽詢過程中提供的資料

3. 利用目的

蒐集的個人資料，將在下列目的範圍內使用：

  • 回覆您的洽詢，以及為此與您聯繫
  • 寄送產品資料・樣品、提供報價
  • NW agent 的引薦對象篩選、引薦與商談支援
  • 向となり旅搶先登記者提供籌備進度與旅遊資訊
  • 介紹本公司的事業與服務
  • 改善服務，以及規劃新服務
  • 依法令所需之處理

4. 提供給第三者

除法令規定的情形外，本公司不會在未事先取得您同意的情況下，將個人資料提供給第三者。

在 NW agent 進行企業引薦時，將事先請您確認提供給引薦對象的資料範圍，並在取得您的同意後提供。

5. 於日本以外地區的處理

本公司於中國（上海）與台灣（台北）設有據點，視諮詢內容，可能於這些國家・地區處理個人資料。屆時，本公司將在掌握當地個人資料保護制度的前提下，採取必要的安全管理措施。

若需將個人資料提供給位於外國的第三者（例如海外的引薦對象企業），本公司將依法令告知提供對象所在的國家・地區名稱，以及當地的個人資料保護制度等資訊，並事先取得您的同意。

6. 業務委託

本公司可能在利用目的範圍內，將部分個人資料的處理委託給外部業者。屆時將慎選受託者，並進行必要且適當的監督。

7. 安全管理

為防止個人資料外洩、滅失或毀損，本公司將限制可存取的人員，並採取其他必要且適當的安全管理措施。

本網站目前未使用流量分析或廣告用途的 Cookie。若日後開始使用，將修訂本政策並公告。
