抗反射膜設計模擬工具
「TMCalc」

只要選擇膜層構成與材料，按下「最佳化」，就能自動算出反射率最低之膜厚的 Excel 工具。我們將自家低反射鍍膜 GLC（Ghost Less Coating）開發時使用的計算方式，開放給所有人使用。

免費下載

主要功能

  • 膜厚自動最佳化

    設定要固定的層與膜厚上下限後按「最佳化」，即可在目標波長範圍內找出反射率較低的膜厚。目前的膜厚也會列入候選，因此結果不會變差。

  • 同時評估多個條件

    可同時評估中心（0°）與斜向入射（例：40°）等最多3個條件。鏡片周邊膜變薄的情形，也能以「倍率」輸入。

  • 切換偏振

    可選擇非偏振（S・P平均）、僅S偏振、僅P偏振。

  • 與實測比較・實測分析

    貼上量測到的反射率，即可與設計比較，並計算各層的推定膜厚，以及配合 PVD 偏差的最外層目標值。

  • 材料表・基板表

    以 Hartmann 公式的係數登錄材料。只知道折射率 nd 的材料，也有產生係數的欄位。

  • Output 工作表

    每次變更設計，都會自動輸出 0〜40°（每10°）・380〜1500nm 的反射率表格與圖表。

使用方法

  1. 從下方按鈕下載您要使用的語言版本。
  2. 以 Excel 開啟，選擇「啟用巨集」（不啟用巨集也能顯示圖表與結果公式）。
  3. 在「設計」工作表選擇膜設計Type、基板與各層材料，並輸入評估條件（入射角）與目標波長範圍。
  4. 按「最佳化」即可自動決定膜厚。請以結果表格與圖表確認是否符合規格。

使用環境與注意事項

  • 請使用 Microsoft Excel（桌面版）。已在 Mac 版 Microsoft 365 的 Excel 上確認運作。Excel 網頁版、Google 試算表、Numbers 無法使用按鈕（巨集）。
  • 在 Windows 上巨集遭封鎖而無法運作時，請在檔案上按右鍵 →「內容」→ 勾選「一般」下方的「解除封鎖」並按「確定」，再重新開啟檔案。
  • 計算前提：無吸收（k=0），不含基板背面反射。入射角為空氣側的角度。計算採用特徵矩陣法。
  • 材料與基板的係數為參考值，請替換為您所使用材料的數值。計算結果為設計參考，並不保證實際產品的特性。
