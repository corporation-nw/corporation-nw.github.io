反射防止膜の設計シミュレーター
「TMCalc」

膜構成と材料を選んで「最適化する」を押すだけで、反射率がいちばん下がる膜厚を自動で計算する Excel ツールです。当社の低反射コーティング GLC（Ghost Less Coating）の検討で使っている計算を、どなたでも使えるようにしました。

無料でダウンロード

できること

  • 膜厚の自動最適化

    固定する層や膜厚の上限・下限を決めて「最適化する」を押すと、目標の波長範囲で反射率が下がる膜厚を探します。今の膜厚も候補に入れるので、押して悪くなることはありません。

  • 複数の条件を同時に評価

    中心（0°）と斜め入射（例：40°）など、最大3つの条件をまとめて評価できます。レンズ周辺で膜が薄くなる分も「倍率」で入れられます。

  • 偏光の切り替え

    無偏光（S・P平均）、S偏光のみ、P偏光のみを選べます。

  • 実測との比較・実測解析

    測った反射率を貼り付けると、設計との比較、層ごとの推定膜厚、PVD のずれに合わせた最終層の狙い値を計算します。

  • 材料表・基板表

    ハルトマンの式の係数で材料を登録します。屈折率 nd しか分からない材料も、係数を作る欄があります。

  • Output シート

    0〜40°（10°刻み）・380〜1500nm の反射率の表とグラフを、設計を変えるたびに自動で書き出します。

使い方

  1. 下のボタンから、使う言語のファイルをダウンロードします。
  2. Excel で開き、「マクロを有効にする」を選びます（グラフと結果の数式はマクロなしでも表示されます）。
  3. 「設計」シートで膜設計Type・基板・各層の材料を選び、評価条件（入射角）と目標の波長範囲を入れます。
  4. 「最適化する」を押すと、膜厚が自動で決まります。結果の表とグラフで規格に入っているかを確かめます。

動作環境と注意

  • Microsoft Excel（デスクトップ版）でお使いください。Mac 版 Microsoft 365 の Excel で動作を確かめています。Excel for the web・Google スプレッドシート・Numbers では、ボタン（マクロ）は動きません。
  • Windows でマクロがブロックされて動かないときは、ファイルを右クリック →「プロパティ」→「全般」の下にある「許可する」にチェックを入れて「OK」を押し、開き直してください。
  • 計算の前提：吸収なし（k=0）、基板の裏面反射は含みません。入射角は空気側の角度です。計算には特性行列法を使っています。
  • 材料・基板の係数は参考値です。お使いの材料の値に置き換えてお使いください。計算結果は設計の目安であり、実際の製品の特性を保証するものではありません。
